# 📊 Simple Linear Regression: Attendance → Final_Score

## 📌 Overview

This model examines the effect of **Attendance** on students' Final Scores.

---

## 🎯 Objective

* Predict Final Score using Attendance
* Measure importance of class participation

---

## 🧾 Feature & Target

* Input Feature (X): Attendance
* Target Variable (y): Final_Score

---

## 🔧 Data Preprocessing

* Missing values handled
* Duplicates removed
* Encoding applied
* Scaling performed

---

## ⚙️ Model Training

* Linear Regression
* 80/20 split

---

## 📈 Model Evaluation

* R² Score

---

## 📊 Visualization

* Scatter plot + regression line

📌 Insight:

* Higher attendance strongly correlates with better performance

---

## 💾 Model Saving

* Model saved using joblib

---

## 🧠 Conclusion

* Regular class attendance significantly improves academic results
